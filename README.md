## Project Description

This project demonstrates Dart variables, data types, arithmetic operators, comparison operators, and console output through a simple student score calculator.

## Data Types Used

- int: Stores the quiz score.
- double: Stores the project score and computed average.
- String: Stores the student's name.
- bool: Stores a true or false value.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
dart run
```
